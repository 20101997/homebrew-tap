# Homebrew tap for Ditty

[Ditty](https://github.com/20101997/Ditty) is the unofficial Mac version of the Windows clipboard manager Ditto.

```sh
brew install --cask 20101997/tap/ditty
```

Update with `brew upgrade --cask ditty`, remove with `brew uninstall --cask ditty`.

Ditty is not notarized by Apple, so this cask clears the download quarantine flag after installing; otherwise macOS would refuse to open the app.
